# 01 Variables

## Overview

This section introduces the fundamentals of working with variables in Python. It focuses on storing different types of data, choosing meaningful variable names, and understanding how values are represented and used in a program.

## Topics Covered

* Variable declaration
* Naming conventions (`snake_case`)
* Basic data types:

  * `str`
  * `int`
  * `float`
  * `bool`

* Assigning values to variables
* Updating variable values
* String concatenation
* f-strings
* Using `print()`

## Practical Exercises

* Creating character attributes for an RPG game
* Building player profiles
* Working with health, gold, and level variables
* Combining variables into readable output
* Formatting text using f-strings

## Skills Gained

After completing this lesson, I can:

* Create and assign variables.
* Choose appropriate data types.
* Use meaningful variable names.
* Display variables using `print()`.
* Combine text and variables with f-strings.
* Organize related data in a readable way.

## Notes

This lesson focuses on writing clean and readable code. Although the programs are simple, good naming conventions and proper formatting are treated as important habits from the very beginning.
