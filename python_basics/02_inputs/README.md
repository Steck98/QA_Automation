# 02 Input

## Overview

This section introduces user interaction in Python using the `input()` function. It covers collecting data from users, converting input into appropriate data types, and displaying formatted output.

## Topics Covered

- Using `input()`
- Converting input with `int()`
- Converting input with `float()`
- Working with user-provided data
- Using f-strings with user input
- Choosing appropriate data types

## Practical Exercises

- Greeting the user
- Character creator
- Rectangle area calculator
- Shopping calculator
- RPG player profile
- Currency and change calculator

## Skills Gained

After completing this lesson, I can:

- Collect input from the user.
- Convert text into numbers.
- Select appropriate data types based on project requirements.
- Format user data using f-strings.
- Build simple interactive console applications.

## Notes

During this lesson, the focus was placed not only on Python syntax but also on choosing appropriate data types based on real-world scenarios and thinking like a QA engineer by considering invalid user input and edge cases.
