# 03 Operators

## Overview

This section introduces arithmetic and comparison operators in Python. It focuses on performing calculations, comparing values, and understanding how operators are used to build program logic.

## Topics Covered

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Floor division (`//`)
* Modulo (`%`)
* Exponentiation (`**`)
* Equality (`==`)
* Inequality (`!=`)
* Greater than (`>`)
* Less than (`<`)
* Greater than or equal to (`>=`)
* Less than or equal to (`<=`)
* Boolean results (`True` / `False`)

## Practical Exercises

* Experience calculator
* Gold bag capacity calculator
* Gold remainder calculation
* Operator experiments
* Comparing values
* Predicting program output

## Skills Gained

After completing this lesson, I can:

* Perform arithmetic operations.
* Use floor division and modulo in practical scenarios.
* Apply exponentiation.
* Compare values using comparison operators.
* Understand boolean results (`True` and `False`).
* Predict the outcome of arithmetic and comparison expressions.

## Notes

This lesson focused on understanding how operators work through experimentation rather than memorizing definitions. Special attention was given to real-world applications of floor division and modulo, as well as understanding why comparison operators return boolean values that are later used in conditional statements.
